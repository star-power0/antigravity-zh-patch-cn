# 故障排查手册

本文档汇总了使用 Antigravity 中文补丁时的常见疑问、排查方法与解决技巧。

---

## ⚡ 快速诊断清单（30 秒自检）

遇事不决，先运行一次环境健康体检：

```bash
install.bat --doctor
# 或
node install.js --doctor
```

正常输出应显示：
* 客户端版本：正常识别（如 `2.21.1`）
* 汉化热注入状态：`已注入生效 [PASS]`
* 官方原版安全备份：`存在 (app.asar.bak) [PASS]`
* 综合评价：`完美健康 (HEALTHY - 100% 准备就绪)`

## 常见问题解答 (FAQ)

### Q1：为什么我的工作区名字（如 CodexWorkspace）或者系统名称（如 Ubuntu）没有被翻译？
* **答**：**这是正常且必须如此的设计！**
  旧版补丁因为使用了失控的 Google 在线机翻，把用户的文件夹名 `CodexWorkspace` 强行机翻为「法典工作区」，把系统名字乱翻，严重破坏用户体验。
  v6.0.0 彻底移除了在线翻译，仅通过本地 744+ 离线词库精确翻译官方界面控件，**坚决不触碰任何用户项目名称、工作区路径与系统专有名词**。

### Q2：为什么 AI 回复正文和代码没有被翻译成中文？
* **答**：**本补丁的定位是 UI 界面汉化，严格隔离 AI 对话与代码编辑器。**
  Antigravity 作为智能体编程助手，对话与编辑区域包含大量源代码、终端命令、文件路径和报错原文。如果全局机翻正文，会导致代码语法被破坏、命令无法运行。
  AI 会自动根据您的中文提问用中文回答，不需要也不应该对其代码进行前端界面强行替换。

### Q3：为什么杀毒软件（卡巴斯基、火绒等）以前会拦截，现在如何处理？
* **答**：
  * **旧版拦截原因**：早期版本生成了 `.vbs` 外部脚本作为启动中转，且在线发送翻译网络请求，被卡巴斯基的主动防御（PDM）判定为可疑脚本启动器。
  * **v6.0.0 解决方案**：新版彻底移除了所有外部启动器脚本和网络请求，直接通过原生 Preload 嵌入。卡巴斯基、火绒零误报，**无需添加任何排除项**。如果安装目录下仍有旧版本残留的 `.vbs`，可直接手动删除。

### Q4：安装后打开客户端，界面仍然是英文怎么办？
* **答**：请按以下顺序排查：
  1. **刷新窗口**：在 Antigravity 界面内按下 **`Ctrl + R`** 强制重新载入界面。
  2. **彻底退出残留进程**：Electron 应用在点击关闭窗口后可能仍有后台进程残留。可在任务管理器中结束所有 `Antigravity.exe` 进程后重新打开。
  3. **运行体检**：执行 `node install.js --doctor`，确认 ASAR 注入状态是否为 `[PASS]`。

### Q5：官方客户端自动更新后汉化失效了？
* **答**：Antigravity 官方在静默推送新版本时，会重新下载并覆盖 `app.asar`。
  遇到此情况，只需重新运行一次 `install.bat`，30 毫秒即可瞬间重新恢复最新汉化。

### Q6：如何彻底卸载补丁并恢复官方原版？
* **答**：在终端执行：
  ```bash
  node install.js --restore
  # 或
  install.bat --restore
  ```
  安装器会自动使用安装时为您妥善保存的 `app.asar.bak` 秒级还原官方原版核心。
