* **版本号**：`v6.0.0`
* **发布日期**：`2026-10-08`
* **适配版本**：Google Antigravity `2.21.1+`（向下兼容 `2.0.11` ~ `2.21.1` 各主流构建）
* **定位**：全量架构重构重大版本（里程碑）

---

## 🚀 核心变更总结

### 1. 架构突破：纯原生内存流 ASAR 极速注入引擎
* 告别解包上千碎文件的历史包袱，全流程基于 Node.js 内存 Buffer 重构 ASAR Header，自动重算数据段偏移与校验和。
* 耗时压缩至 **30 毫秒级**，原地完成热修补，彻底杜绝 Windows 磁盘文件锁死问题。

### 2. 注入升级：Preload 预加载原生热注入
* 注入目标由脆弱的 `utils.js` 升级为 Electron 原生的 `dist/preload.js`。
* 随渲染进程启动即行生效，彻底解决启动时的英文白字闪烁与延迟注入问题。

### 3. 词库革新：744+ 静态精校全量离线大词库
* 静态收录 744+ 高频 UI 词条，完整覆盖菜单栏、设置全项（全局权限、计划审阅策略、安全预设、本地权限等）、模型配额、用量明细、版本对比、终端面板与侧边栏 `Automations`。
* **彻底移除 Google/MyMemory 外部在线翻译 API**，100% 离线运行。
* 彻底消灭将自定义项目名（如 `CodexWorkspace`）误翻为「法典工作区」以及误翻 `Ubuntu` 等专有名词的失控现象。

### 4. 体验优化：独家 `formatQuotaDuration` 紧凑时间算法
* 彻底根治官方模型额度刷新倒计时在窄屏侧边栏下被挤压截断成 `wee...` 的视觉 Bug。
* 动态计时器（思考时长、处理耗时、运行任务数、文件修改数）自然中文化。

### 5. 安全纯净：100% 绿色纯净 · 零杀软误报
* 彻底清理历史遗留的 `.vbs` 外部启动器与常驻守护，卡巴斯基、火绒等主动防御零告警。
* 增加 `--doctor` 健康体检体系与 `--restore` 官方原版一键回滚体系。
